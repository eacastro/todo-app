# Flutter To-Do App

**Flutter To-Do App** es una aplicación en desarrollo diseñada para que cualquier persona a llevar un registro sencillo y efectivo de sus tareas pendientes. Construida con Flutter, este proyecto no solo es un ejercicio práctico de desarrollo, sino también una muestra de mi pasión por crear soluciones útiles y escalables.

¿Buscas inspiración, ideas frescas o talento para tu equipo? Esta app es el punto de partida perfecto para explorar cómo Flutter puede transforma la productividad diaria. ¡Descubre cómo puedes llevar la gestión de tareas al siguiente nivel y anímate a contribuir, mejorar o simplemente disfrutar de la experiencia!

### Características actuales:
- Agregar tareas a una lista.
- Editar tareas agregadas.

### Características planificadas:
- Eliminación de tareas.
- Organización por categorías o etiquetas.
- Recordatorios y fechas límite.
- Integración con Firebase.

## Instalación:

Sigue estos pasos para instalar la app en tu entorno local:

1. **Instala Flutter**
    Descarga e instala Flutter desde el [Sitio oficial](https://docs.flutter.dev/get-started/install) y asegúrate de agregarlo a tu PATH.

2. **Clona el repositorio**
    Abre tu terminal y ejecuta:
    ```
    git clone https://github.com/eacastro/todo-app.git
    cd todo-app
    ```

3. **Instala las dependencias / Ejecuta la aplicación**
    Ejecuta el siguiente comando para instalar los paquetes necesarios:
    ```
    flutter pub get
    ```    
     
4. **Conecta un dispositivo o inicia un emulador**
    Puedes usar un dispositivo físico o iniciar un emulador desde Android Studio o VS Code.

5. **Ejecuta la aplicación**
    Inicia la app con:
    ```
    flutter run
    ```

¡Listo! Ahora puedes explorar y modificar la aplicación en tu entorno local.
