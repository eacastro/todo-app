# Flutter To-Do App

**Flutter To-Do App** es una aplicación en desarrollo pensada para ayudar a cualquier persona a llevar un registro sencillo y efectivo de sus tareas pendientes. Está construida con Flutter y tiene como propósito principal servir como ejercicio práctico de desarrollo móvil, además de formar parte de mi portafolio profesional. 

### Características actuales:
- Agregar tareas a una lista.

### Características planificadas:
- Edición y eliminación de tareas.
- Organización por categorías o etiquetas.
- Recordatorios y fechas límite.
- Integración con Firebase.
